# Artificial-Intelligence

A real-time hand tracking mouse control project built with 
""Python", 
""OpenCV"", 
""MediaPipe"" 
""PyAutoGUI"".

This project allows you to control the mouse cursor without touching a physical 
mouse by using hand gestures in front of the webcam..

---

## Features

- Real-time webcam hand tracking
- Move mouse cursor with index finger
- Left click with thumb + index finger pinch
- Right click with thumb + middle finger pinch
- Scroll mode with index + middle finger
- DPI-aware support for Windows
- Smooth cursor movement
- Clean visual interface with status panels and FPS display

---

## Technologies Used

- Python 3.11
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy
